高级信息

状态与使用

01 / 创建

全部配置一次保存为草稿，尚未进入运行。

02 / 启用

后端校验配置、生成发布版本并加载。成功后显示运行版本。

03 / 开始对话

主 Agent 出现在聊天入口中，子 Agent 由关联的主 Agent 调用。

04 / 持续调整

修改后保存草稿，发布更新才会替换当前运行版本。
