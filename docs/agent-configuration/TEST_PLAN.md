# Agent 配置独立测试计划

日期：2026-09-10；角色：测试工程师 Agent。当前仅完成测试准备，最终结果见候选实现完成后编制的 TEST_REPORT.md。

## 环境与方法

- 使用真实 Spring Boot、H2、HTTP API 和运行时注册表；浏览器交互由根协调代理执行并提供证据。
- 本地确定性 OpenAI 兼容服务 `scripts/mock-openai.mjs` 提供 chat completions、embeddings 和工具回调响应，将完整测试请求写入 JSONL。日志只使用本地合成数据；服务仅监听 127.0.0.1。
- 启动：`node scripts/mock-openai.mjs 18091 tmp/mock-openai-requests.jsonl`，应用设置 `SPRING_AI_OPENAI_BASE_URL=http://127.0.0.1:18091`、`SPRING_AI_OPENAI_API_KEY=local-test-key`。
- `[route:worker_code]` 指定路由目标；未指定时选择系统提示词中的首个合法子 Agent。`[tool:query_order]` 触发已绑定的订单读取工具，用 Spring AI 真实工具调用往返验证工具执行。
- 桩测试验证配置、协议、提示词技能注入、绑定与路由，不验证真实云模型语义质量、MCP 远端服务或生产鉴权。

## 测试矩阵

| 编号 | 场景 | 预期和证据 |
| --- | --- | --- |
| T01 | 页面一次填写名称、简介、提示词、工具、技能创建 worker | 保存回显一致；仅有草稿，未加载，正式入口不可选 |
| T02 | 主 Agent 关联已启用子 Agent | 页面只对主开放关联；快照、运行时子目录一致 |
| T03 | 点击启用 | 校验、生成运行版、注册表加载；API 和正式聊天免重启可调用 |
| T04 | 修改已启用草稿 | 新名称/提示词/工具/技能不影响运行版；再次启用后才生效 |
| T05 | 技能与工具 | 请求日志包含所选技能正文与工具 schema；真实工具往返成功；未选工具不暴露 |
| T06 | 正式聊天选新主、路由新子 | HTTP 正式入口和 UI；返回新子 code，日志体现新主/新子系统提示词 |
| T07 | 停用与依赖（AC10 最终口径） | 允许停用被主引用的子 Agent，移出 Registry、运行时动态过滤；零可用子时明确提示；不能通过旧会话或固定回退绕过；重新发布主时校验依赖 |
| T08 | 重启恢复 | 文件型 H2 重启后已启用运行版恢复、草稿保留且不提前生效 |
| T09 | 输入与角色 | 空白/超长/重复 code/非法 type/未知工具技能/非法 role/缺权限；明确 4xx 且无部分成功 |
| T10 | 主子关系 | 子关联子、自关联、引用主、不存在、停用子、重复引用、空引用，拒绝非法组合 |
| T11 | 并发和事务失败 | stale revision、同时启用/编辑、提交失败；旧运行版和数据库保持一致 |
| T12 | 回归 | 历史种子 Agent、工具目录、版本列表/回滚、会话接口、管理权限与异常返回 |
| T13 | 页面安全和易用性 | 中文/特殊字符回显，脚本作为文本；错误可读、按钮状态、角色权限、切换主入口 |

## 门禁与缺陷记录

P0 数据破坏/系统不可用；P1 创建、启用、加载、正式调用、持久化或主子硬约束失败；P2 非阻断展示/体验缺陷。P0/P1 必须修复复测后关闭。测试只记录已实际执行的证据，未跑的外部模型和生产部署项明确标受限；产品验收必须在独立测试完成之后执行。
