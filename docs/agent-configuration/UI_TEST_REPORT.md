## 验证方法与边界

浏览器视口覆盖 API 在本环境未改变既有页面宽度，因此窄屏验证使用 `.tools/responsive-harness.html` 的同源 iframe，让真实管理页在 390px 布局视口中运行。已检查页面实际尺寸与截图，未把外层 1280px 截图假称手机尺寸；这验证响应式布局和表单可操作性，不替代真实移动设备兼容测试。临时测试标签已关闭。

第一候选曾因多元素选择器误用阻断页面初始化，架构师修复后重新加载并完成以上全部流程。后端初期使用旧编译产物时观察到的 ToolCallback 接口错误也已在候选重编译后通过真实工具调用复测。

模型服务是受控替身，功能断言来自真实模型请求、实际工具返回、数据库与运行状态，不以替身回答质量代表远程模型效果。实际 JVM 重启、事务失败、更多非法参数和权限验证由独立 TEST_REPORT.md 记录。

非阻断观察：当前 ChatResponse.toolCalls 对自动 ToolCallback 往返仍返回空数组；请求日志证明工具真实执行，但对话调试面的工具汇总尚不完整。此项作为 P2 可观测性待办，不宣称完整工具审计已交付。
