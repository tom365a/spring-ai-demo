# 统一资源配置架构设计

日期：2026-09-10；责任：全栈架构师 Agent；基线：PRD R1/1.0。状态：R2设计，后续以最终代码与自测同步修订；不代表测试通过。

## 架构切片与责任

1. 资源/版本/凭证持久化、依赖索引与迁移。
2. 请求资源快照、统一工具执行网关、确认状态机、预算和轨迹。
3. 每Agent模型工厂、HTTP和MCP传输、技能版本解析。
4. 主子编排、记忆裁剪、正式/试运行/测试统一入口。
5. 五页面、差异影响确认、资源关联及诊断。
6. 故障/并发/迁移/重启自测和独立验收。

根协调独占 `infrastructure/resources/transport` 和 pom.xml 新增传输依赖；前端协作者独占 static 下管理/聊天文件；架构师负责其他后端、设计、自测、迁移说明。QA仅在候选之后独立验证，不写业务实现。

## 数据和生命周期

资源统一采用 MODEL/TOOL/MCP/SKILL 类型，每条含稳定ID、全局唯一code、草稿JSON、revision、发布版本及全局启用标记。版本表保存不可变JSON。凭证独立表保存ENV引用或AES-GCM密文，资源版本只引用凭证ID，替换凭证创建新记录，避免草稿覆盖运行凭证。主密钥由独立环境配置提供，不写数据库；接口只返回配置状态。

资源变更使用单实例生命周期协调和数据库事务，提交成功后原子替换发布目录。发布前生成带版本指纹的影响确认信息，防止用户确认旧差异后发布新草稿。默认模型指针持久化。删除检查所有Agent/技能草稿及当前发布引用，历史留墓碑，不级联改写旧快照。

技能采用Agent技能code＋版本显式绑定；其他资源引用稳定身份并在任务开始解析发布版本。任务固定主/子Agent及其资源快照，每次新模型调用、工具执行和转交检查当前启用标记，停用优先。MCP同步先保存候选目录，发布事务更新服务及工具目录；失败保留运行快照。

## 执行架构

模型调用统一使用请求上下文及明确ToolCallbacks，禁止模型侧全局工具自动发现。每Agent模型工厂按资源ID/版本构造Kimi或OpenAI，隔离地址、密钥及参数。Kimi保留完整assistant工具历史；OpenAI通过同样的外部工具循环控制预算。

三类工具进入同一执行网关：身份白名单→全局启用→输入schema→工具批次预占→写权限/确认→执行超时→脱敏轨迹。内置适配只负责调用现有方法，HTTP/MCP只负责运输，不存在测试免确认接口。

确认以持久化动作ID绑定会话、Agent/资源版本、规范化参数、原任务快照、已用轮次及剩余活跃预算。等待确认不消耗活跃预算，30分钟失效；PENDING经原子领取后只能执行一次。版本改变拒绝旧动作并重新发起，不清空既有预算。外部已发送但结果不明标记UNKNOWN，不自动重复写请求。

工具批次按模型一次响应计一轮，在首项执行前预占；每批最多10项，超限整批拒绝；0轮合法；主子各自计数。单工具超时取资源、Agent及根剩余时间最小值。子转交最多一次，不重置根截止时间。当前输入只进入一次，公开历史按已完成问答轮裁剪，内部思考/工具参数不共享。

## 安全与协议

HTTP及MCP固定管理员授权scheme/host/port，明确私网许可；模型参数不可改认证或目标。传输实现限制响应体、禁止重定向、固定已验证DNS解析，防止保留端点与DNS重绑定。所有读写请求第一版均不重试。

标准MCP采用独立Streamable HTTP适配，支持协商的2025-11-25/2025-06-18/2025-03-26版本、initialize/initialized、tools/list分页、tools/call及JSON/SSE响应。项目旧桥明确独立类型，不代替标准协议。工具通过服务ID＋原名识别，模型名称由稳定目录code映射。

## 迁移与验证

种子创建统一内置工具/技能和服务端环境凭证引用的默认模型；迁移保持已有Agent草稿/运行/历史内容，旧技能缺版本引用解析为迁移v1，旧模型缺资源选择使用默认。迁移幂等，不读取根.env，不复制真实Key；验证在独立库和端口完成。

RC01–RC15按TEST_PLAN分组件、Spring/JPA、真实回环协议、浏览器、真实进程重启及根协调极少量Kimi证据。只有全范围候选和独立报告完整，才进入产品签署。
